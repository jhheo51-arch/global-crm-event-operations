# 문서 안내

현재 프로젝트의 기획, 조사, 실행 문서를 한곳에 모았습니다. 처음 읽는 경우에는 아래 순서를 권합니다.

1. [제품 기획서](PRD.md)에서 문제, 범위와 완료 기준을 확인합니다.
2. [프로젝트 기획안](PROJECT-PLAN.md)에서 고객군, 행사 일정과 측정 기준을 확인합니다.
3. [조사 자료](RESEARCH-SOURCES.md)에서 공개 자료의 출처와 사용 범위를 확인합니다.
4. [기획 판단과 검증 과제](PROJECT-NOTES.md)에서 직무 연결과 아직 확인하지 못한 조건을 확인합니다.
5. 로컬 실행이나 데이터 연결이 필요할 때만 [실행 안내](RUNNING.md)를 확인합니다.

이 문서는 가상 행사와 공개 조사 자료를 바탕으로 한 개인 포트폴리오입니다. 실제 고객 명단, 행사 성과와 내부 운영 기준은 포함하지 않습니다.
