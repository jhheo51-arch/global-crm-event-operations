# Global CRM Event Operations

**VIP 행사 전의 초청 이유부터 행사 후 담당 업무까지 연결하는 고객 관계 관리(CRM) 운영안입니다.**

[SCENT LOOP 소개 PDF](public/downloads/SCENT-LOOP-Global-CRM-Portfolio.pdf) | [CRM 운영표 Excel](public/downloads/SCENT-LOOP-CRM-Operations.xlsx) | [프로젝트 기획안](PROJECT-PLAN.md)

아이아이컴바인드의 Global CRM Marketing Specialist 공고를 읽고 만든 개인 프로젝트입니다. SCENT LOOP는 가상의 탬버린즈 카디퓨저 프리뷰 행사이며, 실제 운영 경험이나 성과를 뜻하지 않습니다.

![SCENT LOOP 프로젝트 화면](assets/project-overview.png)

## 어떤 흐름을 설계했나요?

`초청 → 현장 경험 → 마케팅 동의 → 후속 상담과 재방문`

| 단계 | 남기는 정보 |
|---|---|
| 행사 전 | 고객군별 초청 이유, 제외 조건과 담당자 |
| 현장 | 참석, 제품과 향에 대한 관심, 상담 요청 |
| 동의 | 행사 참석과 별도로 확인한 마케팅 수신 동의 |
| 행사 후 | 다음 행동, 담당자, 기한과 완료 근거 |

가상 고객 240명을 네 그룹으로 나누고 행사 8주 전부터 행사 후 30일까지를 설계했습니다. 전환율의 분모를 고정해 계산 기준이 달라지지 않도록 했습니다.

## 어디까지 확인했나요?

고객 단계 합계, 전환율 계산, 누락 업무와 출처 표시를 자동 검사하고 PDF, Excel과 구현의 핵심 수치를 대조했습니다.

고객 수와 전환율은 계산 설명용 가상값입니다. 실제 고객 정보, 매출과 내부 정책은 사용하지 않았으며, 재방문이나 구매 효과는 측정하지 않았습니다. 공개 후기 역시 개별 경험으로만 참고했습니다.

## 직접 확인하기

**PDF에서 판단을 읽고 → Excel에서 계산과 인계 구조를 확인하는 순서**를 권합니다. 운영 웹 화면은 소유자 전용이므로 외부 방문자는 제출자료나 로컬 실행을 이용해 주세요.

Node.js 22 이상에서 저장소 폴더의 터미널에 입력합니다.

```sh
npm ci
npm start
```

터미널에 표시되는 주소를 브라우저로 엽니다. 서울시 데이터 연결 설정과 검사 명령은 [실행 안내](RUNNING.md)에 있습니다.
